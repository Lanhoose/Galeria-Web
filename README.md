# Roleta Pokémon — 100% offline

ROLETA POKÉMON — VERSÃO 100% OFFLINE

COMO JOGAR
1. Baixe o ZIP completo pelo GitHub.
2. Extraia TODO o conteúdo para uma pasta.
3. Abra Roleta_Pokemon_Sprites_Corrigidos.html no navegador.

Não precisa instalar Python, executar um .bat, iniciar servidor, importar
imagens nem conectar à internet. Mantenha o HTML e todas as pastas juntos.

O QUE ESTÁ INCLUÍDO
- 5.147 imagens PNG originais, incluindo os 198 treinadores.
- 2.338 GIFs originais, normais e shiny.
- 1.186 arquivos de vozes dos Pokémon.
- Pokémon das nove regiões e formas alternativas, regionais, Mega e Gigantamax.
- Artes oficiais, sprites pequenos, letras Unown, itens, insígnias e cenários.
- Animações com a mesma desaceleração da roleta original, sem chamadas de rede.

Todos os arquivos necessários ao HTML estão incluídos neste ZIP. Os 198
PNGs de treinadores anteriores foram preservados sem alteração; também
permanecem incorporados no HTML.

O servidor original não fornece animação para 17 formas (34 arquivos ao
contar normal e shiny). Nesses casos, a roleta usa o artwork original
correspondente incluído no pacote, mantendo o comportamento que já existia.

PROGRESSO E FUNCIONALIDADES
A lógica de jogo, batalhas, eventos, regiões, desafios, itens, transformações,
PC, conquistas, gravação, som e exportação/importação de progresso foi
preservada. As mudanças se limitam ao carregamento local dos recursos.

O progresso continua salvo neste navegador. Para transferir o progresso de
outra versão, use Configurações > Exportar progresso na versão antiga e
Configurações > Importar progresso nesta versão.

Não abra o HTML de dentro do ZIP: extraia a pasta completa primeiro.

ARQUIVOS DE CONFERÊNCIA
assets/integridade.json: SHA-256 dos arquivos deste pacote.
assets/validacao_midia.json: contagem e conferência das mídias originais.
assets/validacao_navegador.json: resultado dos testes sem acesso à internet.
assets/download_manifest.json: caminhos e fontes originais dos recursos.
